Reinforcement Learning

How an agent learns a good strategy purely from trial and error -- by acting, observing rewards, and gradually improving its decisions -- applied here to an agent that must find its way across a 10×10 grid full of walls and danger zones.

Problem Context: Why a Grid-Navigation Agent?

The earlier modules in this project (Linear Regression, Logistic Regression, Random Forest, K-Means) all learn from a fixed, already-labeled or already-collected dataset: the data exists before training starts, and the model never changes the data by acting on it. Reinforcement Learning is a fundamentally different setting: there is no dataset to begin with. Instead, an agent generates its own experience by acting inside an environment, and must learn, purely from the rewards and penalties it receives along the way, which actions lead to good outcomes. This project extends the 4×4 maze exercise developed in class into a larger, more irregular 10×10 grid, with walls that block movement and danger zones that are survivable but costly -- closer to a real path-planning problem than the original toy example.

Why Reinforcement Learning and Not Supervised Learning?

Imagine trying to solve this grid with the supervised techniques used earlier in this project. We would need a table of examples saying, for every one of the 100 cells, "the correct move from here is Down." Nobody gave us that table, and building it by hand would already require solving the maze. The agent only knows what happens after it acts: a small penalty for a normal move, a bigger one for bumping into a wall, a steep one for a danger zone, and a large reward for reaching the goal. Reinforcement Learning is designed for exactly this situation, where the correct answer is never shown and has to be discovered through interaction.

A second difference is that rewards are delayed. Standing at cell (8, 8), the agent receives the +100 only after the final move into the goal, yet every earlier step in the path contributed to getting there. The discount factor γ and the Bellman update are what carry that distant reward backwards, so cells far from the goal gradually inherit a useful Q-value from the cells closer to it. A model that only judged each step in isolation could never learn that a -1 move can be the right choice if it leads to +100.

Finally, in this grid the agent must balance exploration and exploitation in a very visible way. If it always repeats the first route that worked, it may settle for a path that crosses a danger zone and never find the safer one; if it explores forever, it never takes advantage of what it learned. That is why ε starts at 1.0 (pure exploration) and decays toward 0.05 as the episodes go by. The success percentage and the learned path shown on the Application page are the direct result of that trade-off.

The Grid World

The agent starts at the top-left corner and must reach the goal at the bottom-right corner, choosing one of four moves at every step:

A Agent start (1 cell)
T Target / goal (1 cell)
o Open path (68 cells)
# Wall (20 cells)
D Danger zone (10 cells)

Walls simply block movement (the agent cannot step onto a "#" cell). Danger zones ("D") are different: the agent can walk through them, but doing so costs a steep penalty, so a well-trained agent learns to avoid them whenever a similarly short, safer route exists -- without being told explicitly "avoid D", only through the reward it receives for stepping there.

  • Agent: the decision-maker -- here, the entity trying to navigate from the start cell to the goal cell.
  • Environment: everything the agent interacts with and has no direct control over -- the 10×10 grid itself, with its fixed walls and danger zones.
  • State (s): a complete snapshot of the situation the agent needs to decide what to do next. In this exercise a state is simply the agent's current (row, col) position on the grid.
  • Action (a): one of the four moves available at every state: Up, Down, Left, Right.
  • Step: one state → action → next-state transition. Taking a step is the basic unit of interaction between the agent and the environment.
  • Episode: one complete attempt, from the start cell until the agent either reaches the goal or runs out of allotted steps. Training repeats many episodes, and the agent's behavior (hopefully) keeps improving from one episode to the next.

  • Immediate reward (r): the single number the environment hands back right after a step, telling the agent how good or bad that one move was.
  • Penalty: a negative reward -- used here for invalid moves (walking into a wall or off the grid) and for stepping onto a danger zone.
  • Experience: the full record of one step -- (state, action, reward, next_state) -- which is exactly what the agent uses to update what it has learned.

This exercise's reward system:

EventRewardWhy
Move to an open cell-1Small step cost, so the agent is pushed toward the shortest path, not just any path.
Invalid move (wall / off-grid)-5Discourages wasting steps on illegal moves, more strongly than a normal move.
Step onto a Danger Zone-20Allowed, but costly enough that a safer route of similar length is preferred.
Reach the Goal+100Large positive signal that clearly marks success and ends the episode.

  • Policy (π): the agent's strategy -- a rule for picking an action given a state. The goal of training is to end up with a good policy.
  • Exploration: occasionally taking a random action instead of the one currently believed to be best, so the agent keeps discovering new parts of the grid and doesn't get stuck prematurely committing to a mediocre route.
  • Exploitation: taking the action currently believed to be best, to make the most of what has already been learned.
  • Epsilon-greedy (ε-greedy): the specific exploration strategy used here -- with probability ε take a random action (explore), otherwise take the best known action (exploit). ε starts high (mostly random movement, to see as much of the grid as possible) and decays every episode toward a small minimum, so the agent shifts from exploring to exploiting as it learns.

  • Return: the total accumulated reward over an episode (or from some point onward) -- what the agent is ultimately trying to maximize, not just the reward of the very next step.
  • Discount factor (γ, gamma): a number between 0 and 1 (0.95 here) that controls how much a future reward counts compared to an immediate one. A reward many steps away is worth γ raised to that many steps, which both keeps the math well-behaved and reflects that a reward obtained sooner is generally preferred.
  • State value V(s): how good it is to be in state s, assuming the agent then follows its current policy -- the expected return starting from that state.
  • Action value Q(s, a): how good it is to take action a in state s, and then follow the policy afterward. This is the quantity this exercise actually learns and uses to decide how to move.

Q-Learning updates its estimate of Q(s, a) after every single step, using the step's observed reward plus the best Q-value available from the next state (the Bellman equation):

Q(s, a) ← Q(s, a) + α · [ r + γ · maxa' Q(s', a') − Q(s, a) ]

where α (alpha) is the learning rate, controlling how much each new experience overwrites the previous estimate.

Instead of storing Q(s, a) in a plain lookup table, this exercise estimates it with a single scikit-learn SGDRegressor, trained incrementally with partial_fit() -- the same approach developed in class for the smaller 4×4 maze. Each (state, action) pair is one-hot encoded into its own feature vector, so the regressor can give every pair its own independent value, exactly as a lookup table would, while technically remaining a function approximator trained the way the activity requires. model.predict() is what produces every Q-value, path, and evaluation step shown on the Application page.
