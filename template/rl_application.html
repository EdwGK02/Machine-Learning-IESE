8. Interpreting the Training Results

The numbers above describe two different things: how the agent behaved while learning (success rate, average reward, final ε) and how good the finished policy is (the greedy path and its reward). Reading them together tells you far more than any single figure.

Success rate: how quickly the agent learned

{{ stats.successful_episodes }} of {{ stats.episodes }} training episodes ({{ stats.success_pct }}%) ended at the goal. This figure includes the opening episodes, when ε was close to {{ epsilon_start }} and the agent was moving almost at random, so it can never reach 100% even for a perfect agent. {% if stats.success_pct >= 80 %} A rate this high means the agent discovered a route to the goal early and then reused it reliably as exploration faded. {% elif stats.success_pct >= 50 %} A moderate rate means the agent found the goal, but only after a sizeable stretch of trial and error; the second half of training was probably much more successful than the first. {% else %} A low rate means the agent spent most of its episodes failing to reach the goal within the step limit. Either the grid is hard to explore at random, or the exploration schedule did not give it enough useful experience. {% endif %} Remember that ε ended at {{ stats.final_epsilon }} {% if stats.final_epsilon <= epsilon_min %} (its floor of {{ epsilon_min }}), so the last portion of training was almost entirely exploitation of what had been learned. {% else %} (still above its floor of {{ epsilon_min }}), so the agent was still exploring noticeably when training stopped. {% endif %}

Average reward: speed and safety combined

The average reward of {{ stats.average_reward }} is taken over all {{ stats.episodes }} episodes, so, like the success rate, it is dragged down by early exploration. It blends two effects: how often the agent reached the goal (+100) and how costly the journey was (−1 per move, −5 per invalid move, −20 per danger-zone step). An episode that reaches the goal quickly ends with a large positive total, while one that times out can accumulate a deeply negative total. {% if stats.average_reward < 0 %} A negative average therefore does not mean the final policy is bad; it mostly reflects the penalties paid during the exploratory phase. {% else %} A positive average indicates that successful, efficient episodes outweighed the penalties paid during exploration. {% endif %} The cleaner measure of policy quality is the total reward of the greedy run ({{ result.total_reward }}).

Learned path: the real test of the policy

{% if result.reached_goal %} With exploration switched off, the trained agent reached the goal in {{ result.n_moves }} moves for a total reward of {{ result.total_reward }}. Because every move costs −1, a total reward close to 100 − (path length) means the agent took an efficient route and avoided danger zones; a noticeably lower total points to detours, invalid moves, or steps through D cells. Check the step-by-step table in section 6: any “Danger Zone” or “Invalid move” rows show exactly where the policy is still imperfect. {% else %} With exploration switched off, the trained agent did not reach the goal in {{ result.n_moves }} moves (total reward {{ result.total_reward }}). Look at the path in section 5: a policy that loops between the same cells or keeps bumping into a wall usually means the Q-values in those cells are too similar to rank actions correctly. {% endif %}

Why the Q-values are only an approximation

Q-Learning first builds an exact table of values, but the policy you see is driven by a separate SGDRegressor fitted to that table with {{ stats.calibration_epochs }} passes of partial_fit(). Each state-action pair is encoded as a single one-hot vector, so the model has one weight per pair and can in principle reproduce the table exactly. However, because each pair is seen only {{ stats.calibration_epochs }} times and the learning rate decays, the predicted values in section 7 may be compressed toward zero compared with the original table. What matters for behavior is the ranking of the four actions in each row, which is usually preserved. If the success rate is high but the goal is not reached in evaluation, the gap is most likely caused by this calibration step rather than by the Q-Learning itself.

How the hyperparameters shaped the outcome
  • α = {{ alpha }} controls how far each experience moves a Q-value toward its Bellman target; in a deterministic grid, a moderately high value speeds up learning without much risk of instability.
  • γ = {{ gamma }} sets how much future reward counts. The +100 goal reward is discounted by γ for every step of distance, producing a gradient of values that points the agent toward the goal and makes shorter routes more valuable than longer ones.
  • ε decays from {{ epsilon_start }} to {{ epsilon_min }}, shifting the agent from exploring the map to exploiting it. The {{ stats.n_states_learned }} states learned out of {{ rows * cols }} grid cells show how much of the map exploration actually covered (walls cannot be entered, so they are never learned).

High success rate, goal not reached in evaluation Q-Learning worked, but the SGDRegressor calibration lost the ranking of actions; add calibration epochs or raise the learning rate.
Low success rate and few states learned Exploration never reached the goal often enough; more episodes or a slower ε decay would help.
Goal reached but the path crosses D cells or takes detours The policy is workable but not yet optimal; more training lets the −20 penalties and −1 step costs refine the values.
