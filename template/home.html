About this project

We started by implementing the Linear Regression model along with an applied example that predicts ice cream sales based on temperature. Then, we extended the project by adding two more classification models: — Logistic Regression and Random Forest. — Both models include an application example based on predicting whether a student is likely to pass a course, considering factors such as study hours, attendance, and previous grades. Each section explains the concepts used throughout the project.
