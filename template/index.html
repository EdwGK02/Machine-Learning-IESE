¿Qué es Machine Learning?

El Machine Learning (aprendizaje automático) es una rama de la inteligencia artificial que permite a los sistemas aprender patrones a partir de datos, sin ser programados explícitamente para cada tarea.

Tipos de Machine Learning

1. Supervised learning

In supervised learning, the idea is to train a model so that it learns the relationship between the input data and the output data. To achieve this, the algorithm receives a dataset where each example has a correct answer associated with it. Its goal is to discover the rule that connects the input data to those answers.

Supervised learning has two important branches:

1. Classification (categorical variable): It assigns each element to a predefined category or class.

For example, in medical diagnosis, a system classifies a patient as healthy or sick based on their symptoms and clinical tests. The algorithm learns from thousands of previous cases where the correct diagnosis was already known.

2. Regression (numerical variable): Regression predicts a continuous numerical value. The output variable can take any value within a range.

For example, House price prediction: The system estimates the price of a house based on features such as square meters, location, number of rooms, age, etc. The algorithm learns the relationship between these features and the final price from past sales.

2. Aprendizaje No Supervisado

El modelo trabaja con datos sin etiquetar y busca patrones o agrupaciones por sí mismo. Ejemplo: segmentación de clientes según su comportamiento de compra.

3. Aprendizaje por Refuerzo

El modelo aprende mediante prueba y error, recibiendo recompensas o penalizaciones según sus acciones. Ejemplo: un agente que aprende a jugar ajedrez o videojuegos.
