What is Machine Learning?

Machine Learning is a branch of artificial intelligence that allows systems to learn patterns from data, without being explicitly programmed for each task.

Types of Machine Learning

1. Supervised Learning Labeled Data

The model learns from labeled data (where the correct answer is already known). It maps inputs to known outputs by finding patterns in the training examples. Supervised learning has two important branches:

Classification (categorical variable)

It assigns each element to a predefined category or class.

Example: in medical diagnosis, a system classifies a patient as healthy or sick based on their symptoms and clinical tests.

Regression (numerical variable)

Regression predicts a continuous numerical value. The output variable can take any value within a range.

Example: house price prediction — the system estimates the price of a house based on features such as square meters, location, and number of rooms.

2. Unsupervised Learning Unlabeled Data

These algorithms draw inferences from unlabeled datasets — datasets that do not contain predefined answers — in order to identify hidden patterns or structures within the data. This approach has an exploratory nature and is useful when organizations have large amounts of raw data but limited knowledge of the relationships within it.

K-means Clustering

Assigns data points to K groups, where points that are closest to a given centroid are grouped into the same cluster. K represents the number of clusters to be found.

Hierarchical Clustering

Includes agglomerative clustering, in which data points are initially placed into separate groups and then iteratively merged based on their similarity until a single cluster (or the desired number of clusters) remains.

Probabilistic Clustering

Groups data points based on the probability that they belong to a particular distribution.

These algorithms are often behind recommendation systems, based on the concept of "customers who bought this also bought…".

3. Reinforcement Learning Trial & Error

Reinforcement learning is a machine learning technique that trains software to make decisions in order to achieve the best possible results. It mimics the trial-and-error learning process that humans use to achieve their goals. Actions that work toward the goal are reinforced, while those that deviate from it are discouraged.

RL algorithms use a reward-and-punishment paradigm when processing data. They learn from the feedback on each action and discover on their own the best paths to achieve the final results.

Example: an agent learning to play chess or video games.

Excels in complex environments

Reinforcement learning algorithms can be used in complex environments with many rules and dependencies.

Requires less human interaction

The algorithm learns on its own, while still offering mechanisms to integrate human feedback — allowing systems that adapt to human preferences, experience, and corrections.

Optimizes for long-term goals

Reinforcement learning is intrinsically focused on maximizing long-term rewards, making it well-suited for scenarios where actions have prolonged consequences and immediate feedback is not always available.
