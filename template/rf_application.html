Random Forest Application

Predict whether a student will pass or fail a course using a Random Forest model.

Problem Context

This model analyzes student performance data to classify whether a student is likely to pass or fail a course. The dataset contains three independent variables: the number of study hours per week, the attendance percentage, and the score obtained in a previous exam. The target variable is binary: 0 = Fail and 1 = Pass.

Model Process

CSV Dataset → Pandas → X (3 features) and y → 80/20 Split → Random Forest Training → Predictions → Evaluation → New Classifications.

Unlike the Logistic Regression model, which uses a single independent variable, this Random Forest model is trained using three independent variables at once, which lets it capture more complex, non-linear relationships in the data.
