Logistic Regression

Logistic regression is a supervised learning statistical method used to model the probability of a binary event occurring (two possible outcomes: 0 or 1, yes or no, true or false). Unlike linear regression, its output is always between 0 and 1, making it ideal for classification problems.

From a line to a probability

p = 1 / (1 + e^-(mx + b))

The predictor variables and the binary variable to be predicted are collected. Then the coefficients (m and b) are fitted using maximum likelihood, which looks for the values that best explain the data. With those coefficients, the model applies the sigmoid function to the linear combination (mx + b) and returns a probability between 0 and 1. A threshold is then applied (usually 0.5): if the probability is higher, it is classified as 1; if lower, as 0. Finally, it is evaluated with metrics such as accuracy, precision, recall, and AUC-ROC.

Key terms

Sigmoid function

"S"-shaped function that transforms any real value into a range between 0 and 1, converting the linear combination into a valid probability. It is the heart of the model. Its formula is this: σ(z) = 1 / (1 + e^-z)

Maximum Likelihood

Estimation method that finds the values of m and b that maximize the probability of having observed the data. It is used because there is no closed-form solution for logistic regression. Its formula is this: L(m, b) = Π pᵢ^yᵢ · (1 - pᵢ)^(1-yᵢ)

Odds

Relationship between the probability of an event occurring and the probability of it not occurring. Logistic regression directly models its logarithm. Its formula is this: Odds = p / (1 - p)

Log-odds

Natural logarithm of the odds. It connects probability (bounded between 0 and 1) with the predictor variables (unbounded), allowing the model to be treated as a linear equation. Its formula is this: logit(p) = ln(p / (1 - p)) = mx + b
