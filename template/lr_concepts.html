Linear Regression

Linear Regression is a supervised learning technique that models the relationship between an input variable and an output variable by fitting a straight line through the data. It's the technique behind our ice cream sales predictor.

The equation

y = mx + b

Given an input x, the model predicts an output y using a slope m and an intercept b. Training the model means finding the values of m and b that make this line fit the training data as closely as possible.

Key terms

Slope (m)

How much the predicted output changes for every one-unit increase in the input. In our case, how many more ice creams get sold per extra degree of temperature.

Intercept (b)

The predicted output when the input is zero. It's where the line crosses the y-axis.

Residual

The difference between a real data point and what the line predicted for it. Training tries to make these differences as small as possible overall.

R² score

A number between 0 and 1 that shows how well the line explains the variation in the data. Closer to 1 means the line fits the data very well.

MAE (Mean Absolute Error)

The average size of the prediction errors, in the same units as the output. A lower MAE means more accurate predictions on average.

Overfitting

When a model fits the training data too closely, including its noise, and ends up performing worse on new, unseen data.

Predicting ice cream sales from temperature

Our model was trained on historical records that pair a day's temperature with the number of ice creams sold that day. It learned a slope and an intercept that describe how sales tend to rise as temperature goes up.
