Clustering Application

K-Means (scikit-learn) applied to {{ n_records }} motorcycles described by 6 numerical variables, to discover data-driven technical segments.

1. Dataset and Variable Justification

The dataset contains {{ n_records }} motorcycles (well above the 1,000-record minimum), directly related to the group's registered topic (grouping motorcycles according to their technical characteristics). Six numerical variables were selected because together they describe a motorcycle's mechanical identity and market positioning, letting K-Means separate segments such as commuter, naked, sport and touring motorcycles on more than a single dimension:

Displacementcc
PowerHP
Weightkg
PriceCOP
Fuel Economykm/L
Max Speedkm/h

2. Preprocessing

  • Data validation: the generated dataset was checked for missing values and out-of-range values before use (none were found, since it is generated programmatically from realistic bounds per segment).
  • Feature scaling (StandardScaler): the six variables use very different scales (e.g. price in tens of millions vs. fuel economy in km/L). Without scaling, K-Means' Euclidean distance would be dominated almost entirely by price and displacement. Each variable was standardized to mean 0 and standard deviation 1 before clustering.
  • Feature selection: all six variables were kept, since each contributes a distinct aspect of a motorcycle's technical profile that the others do not fully capture.

3. K-Means Configuration (scikit-learn)

KMeans(n_clusters=4, init="k-means++", n_init=10, max_iter=300, random_state=42)

  • n_clusters = 4: chosen to match the four motorcycle segments identified conceptually for this topic (urban, naked/mixed-use, sport, touring).
  • init = "k-means++": smarter centroid initialization than purely random, which speeds up convergence and avoids poor local minima.
  • n_init = 10: the algorithm is run 10 times with different centroid seeds, keeping the best result (lowest inertia).
  • random_state = 42: fixes the randomness so results are reproducible for every teammate and every deployment.

7. Clustering Evaluation: Silhouette Score

Silhouette Score{{ silhouette_score }}

The silhouette score ranges from -1 to 1 and measures how similar each motorcycle is to its own cluster compared to the nearest other cluster. Values close to 1 indicate compact, well-separated clusters; values near 0 indicate overlapping clusters; negative values suggest records may be in the wrong cluster. 8. Interpretation: What Each Cluster Means

The four clusters map cleanly onto real motorcycle market segments: Cluster 1 groups small, cheap, fuel-efficient commuter bikes; Cluster 2 groups mid-range naked/all-purpose bikes; Cluster 3 groups powerful, fast, low-economy sport bikes at a premium price; and Cluster 4 groups the heaviest, large-displacement touring and adventure bikes, prioritizing comfort and range over top speed. This matches the intuitive segmentation the group expected from the topic, but K-Means derived it purely from the numerical similarity between motorcycles, without being told the segment names in advance -- which is the core value of unsupervised learning for this kind of problem: it can reveal (or confirm) a market structure directly from the data.
