What is Machine Learning?

Machine Learning is a branch of artificial intelligence that allows systems to learn patterns from data, without being explicitly programmed for each task..

Key vocabulary

Dataset

The collection of examples used to teach the model, such as our table of past temperatures and the ice cream sales recorded on those days.

Features

The input variables the model uses to make a prediction. In our case, the temperature is the feature.

Label

The value the model is trying to predict. Here, that's the number of ice creams sold.

Model

The mathematical relationship the algorithm builds between features and labels once training is done.

Training vs. testing

Part of the data is used to teach the model (training) and a separate part is held back to check how well it generalizes (testing).

Error / loss

A measure of how far the model's predictions are from the real values. Lower error means a better fit to the data.

How a model learns: the general workflow

Collect data

Gather real examples, like historical temperature and sales records.

Prepare it

Clean and organize the data so the algorithm can use it consistently.

Train the model

The algorithm looks for the pattern that best explains the training examples.

Evaluate it

Test the model on data it hasn't seen to measure how accurate it really is.

Predict

Use the trained model on new inputs, like a new temperature reading.
